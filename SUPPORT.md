# Support

TerraGuard is free and maintained in the open. Help is offered on a best-effort basis.

| You want to | Go to |
|---|---|
| Ask a question or share an idea | [Discussions](https://github.com/Karthik-099/TERRAGUARD/discussions) |
| Report a bug | [New bug report](https://github.com/Karthik-099/TERRAGUARD/issues/new?template=bug_report.yml) |
| Report a wrong finding | [False positive](https://github.com/Karthik-099/TERRAGUARD/issues/new?template=false_positive.yml) |
| Ask for a rule or a format | [Rule request](https://github.com/Karthik-099/TERRAGUARD/issues/new?template=rule_request.yml) |
| Report a vulnerability | Privately, as described in [SECURITY.md](SECURITY.md). Never in a public issue. |

Before opening an issue:

- Run `terraguard version` and include the output.
- Reduce the input to the smallest file that shows the problem, and remove secrets and real account IDs.
- For a wrong finding, include the rule ID and why the configuration is safe.

Documentation: [README](README.md), [Reference](docs/REFERENCE.md), [Architecture](docs/ARCHITECTURE.md),
[Guarantees and limits](docs/LIMITS.md), [Rules](docs/RULES.md), [Self-hosting](docs/SELF_HOSTING.md).
